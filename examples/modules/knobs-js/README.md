# knobs-js

Two knobs of each composition the design system has — `knob` (radial
progress), `knobfull` (rotary pointer), `knobarc` (gauge arc, 300° with a
gap at the bottom) — each driven by its own encoder (1-6; 7-8 unused),
ranging 0-100, vertically centered in the content band between the header
and status bar. Built as a quick test bench for knob rendering
(anti-aliased, `knobStroke = 2`) — turn any encoder and watch its knob
track live, and compare all three compositions side by side.

Demonstrates the endless-encoder convention: each value clamps at its
accumulator, so turning past 0 or 100 stops there and reverses
immediately instead of wrapping back around. Also demonstrates `Knob`'s
`Color` field: every knob here gets its own `push3.Palette` color
(sky/lime/violet/pink_hot/orange/amber) instead of relying on the host
Theme's default fill — leave `Color` unset in your own module and it
falls back to `Theme.Select`, same look every knob had before this field
existed.

Colors come from `palette.json` (generated by `cmd/genpalette` from
`core/push3.Palette`, regenerate with `go run ./cmd/genpalette` from the
repo root after any palette change) — `paletteColor(name)` for the six
knobs, `paletteById(0)` for the background, rather than hand-copied RGB.
See [writing-a-process-module.md](../../../docs/guides/writing-a-process-module.md#colors).

```bash
go run ./cmd/pushapp -install examples/modules/knobs-js
go run ./cmd/pushapp -module knobs-js
```
